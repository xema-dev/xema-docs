# Biome Examples

Worked examples showing complete, runnable biomes from scratch.

## Examples

| Example | Complexity | What it shows |
|---|---|---|
| [Hello Biome](./01-hello-biome.md) | Starter | Minimal biome: one workflow, one skill, no backend |

## What to expect

Each example includes:

- A complete `xema-biome.json` manifest.
- All referenced files (workflows, skills, agents).
- Local validation and sandbox install steps.
- Notes on what to change for a real use case.
